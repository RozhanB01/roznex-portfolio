# ROZNEX Security Policy

ROZNEX takes security and privacy issues seriously.

## Reporting a vulnerability

Please use the contact section on the live ROZNEX website and include **Security report** in the subject or first line:

https://roznex-portfolio.vercel.app/#contact

Please include:
- the affected URL or feature;
- clear reproduction steps;
- expected vs. actual behavior;
- screenshots or request/response details when useful.

Do not include passwords, private tokens, customer data, or other secrets in a public GitHub issue.

## Scope

The public portfolio, project-intake flow, private SmartQuote access flow, and ROZNEX administration endpoints are in scope. Third-party services such as Vercel, GitHub, Google Fonts, and connected storage providers are governed by their own security programs.

## Disclosure

Please allow reasonable time for validation and remediation before public disclosure.
