ROZNEX / PROJECT INTAKE

پروژه‌ات را ثبت کن.

این مرحله فقط برای شناخت اولیه پروژه است و هیچ قیمت عمومی نمایش داده نمی‌شود. پس از بررسی درخواست، در صورت مناسب بودن پروژه، Roznex دسترسی اختصاصی SmartQuote را برای شما ارسال می‌کند.

فرم درخواست پروژه

اطلاعاتی را بنویسید که برای بررسی اولیه پروژه لازم است.

01
ثبت این فرم به معنی تأیید پروژه یا اعلام قیمت نیست. Roznex ابتدا Scope و نیاز پروژه را بررسی می‌کند و سپس در صورت تأیید، دسترسی خصوصی قیمت‌گذاری و پیش‌فاکتور صادر می‌شود.
01ثبت درخواستاطلاعات اولیه پروژه بدون نمایش قیمت ثبت می‌شود.
02بررسی توسط Roznexنیازها، Scope و تناسب پروژه بررسی می‌شود.
03دسترسی اختصاصیپس از تأیید، کد SmartQuote برای مشاهده پکیج‌ها و ساخت پیش‌فاکتور ارسال می‌شود.
