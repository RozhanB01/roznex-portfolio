The ROZNEX studio website, a published in-house project combining visual design, multilingual content, web engineering and a project intake flow.

Published · this websiteAgency / corporate website2026

A digital studio needs to demonstrate design craft while making its services and the next step clear to potential clients.

Context

This in-house project presents ROZNEX services in web design, interactive experiences, AI, and technical SEO. Visitors can navigate from the homepage to services, articles, case studies, and the project inquiry flow.

StatusPublished · this website
AreaAgency / corporate website
Languagesفارسی / English
CoreWeb / SEO / Content

Challenge

Balance distinctive visual identity with practical accessibility: RTL Persian content, an English edition, mobile presentation, indexable pages, and a clear contact path.

Implemented structure

  • Separate Persian and English homepages and dedicated service and case-study pages.
  • Editorial insights pages and related internal links.
  • Multi-step inquiry form with draft saving in the browser.
  • Page-specific metadata, sitemap, hreflang and structured data.

Design decisions

Useful content before decoration

Visual elements should support service clarity rather than hide the next step.

Independent language pages

Persian and English versions have separate URLs and metadata.

Honest project status labels

Published demos and in-progress product work are distinguished.

Status and live website

This website is publicly accessible on the official ROZNEX domain. Public availability does not mean every interactive feature has been independently verified across devices; operational tests are handled separately.
