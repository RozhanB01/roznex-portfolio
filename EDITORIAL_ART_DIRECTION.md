# ROZNEX — topic-specific editorial illustration set

**Scope:** five bespoke SVG illustrations, authored as lightweight repository assets for the article index and explanatory articles. They contain no robot or ROZNEX hero artwork and are not photographs of projects.

- `article-ai-workflow.svg`: automation flow and operational handoffs
- `article-ai-security.svg`: private, layered access controls and protected system boundaries
- `article-seo-performance.svg`: performance graphs and technical diagnostics
- `article-multilingual.svg`: paired localized pages, not a single mixed-language screen
- `article-3d-architecture.svg`: spatial geometry and 3D interface architecture

**Visual rules:** restrained architectural forms, cream/charcoal/copper tones, unique composition per topic, no floating robot, no invented analytics metrics, no screenshots implied to be real products. SVGs use native shapes and gradients without external font/network dependencies.

The article index uses distinct editorial images instead of repeating generic site-hero content. Existing project photos and the flagship robot hero are unchanged.
