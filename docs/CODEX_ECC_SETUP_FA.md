# اتصال اختیاری ECC به Codex

این سند، روش نصب **Everything Claude Code (ECC)** در Codex روی رایانهٔ توسعه‌دهنده را توضیح می‌دهد. وجود این سند به‌معنای نصب یا فعال بودن ECC در محیط اجرا یا حساب ChatGPT نیست.

## نصب توصیه‌شده (Codex CLI جدید)

در ترمینال همان دستگاهی که Codex CLI روی آن نصب و وارد حساب شده است:

```powershell
codex plugin marketplace add affaan-m/ECC
codex plugin add ecc@ecc
codex plugin list --json
```

منبع: https://github.com/affaan-m/ECC (بخش «Codex App and CLI»). در داخل Codex می‌توان `$configure-ecc` را برای تنظیمات اختیاری اجرا کرد. پیش از اعتماد به hookها، محتوا و سطح دسترسی آن‌ها را بررسی کنید.

**فقط یک مسیر نصب:** افزونهٔ بومی Codex و اسکریپت قدیمی `scripts/sync-ecc-to-codex.sh` را هم‌زمان اجرا نکنید. اگر Codex فرمان `plugin` را نمی‌شناسد، ابتدا نسخه و مستندات Codex را بررسی کنید؛ با کپی تنظیمات ناشناس جایگزین نکنید.

## استفاده در این مخزن

- فایل `AGENTS.md`، قواعد اختصاصی پروژه و گام‌های راستی‌آزمایی را برای Codex مشخص می‌کند؛ حتی بدون ECC نیز قابل استفاده است.
- ECC صرفاً به جریان کار ایجنت کمک می‌کند؛ خودِ آن جایگزین تست، بازبینی انسانی، مجوز دسترسی، تأیید PR یا استقرار نیست.
- نصب افزونه، هیچ دسترسی خودکاری به حساب GitHub، رمزها یا سرویس‌های Production نمی‌دهد. هیچ توکن یا فایل `.env` را در مخزن ثبت نکنید.
- تغییرات برنامه‌نویسی ابتدا در شاخهٔ مجزا و Pull Request بررسی شوند. هیچ hook یا MCP بدون بازبینی فعال نشود.

## تأیید اتصال

1. `codex plugin list --json` باید افزونهٔ `ecc@ecc` را نشان دهد.
2. مخزن را در Codex باز کنید و مطمئن شوید `AGENTS.md` خوانده می‌شود.
3. یک وظیفهٔ کوچک و غیرمخرب (مثلاً بررسی README و پیشنهاد برنامهٔ تست) انجام دهید.
4. اجرای آزمایش واقعی و نتیجهٔ آن را جداگانه گزارش کنید؛ وجود این فایل‌ها به‌تنهایی اثبات اجرای ECC نیست.
