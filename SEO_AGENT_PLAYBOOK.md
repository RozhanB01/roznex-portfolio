# ROZNEX SEO Agent / Growth Command Center

**Status:** GitHub Actions read-only SEO monitoring, scheduled each Monday at 06:21 UTC and available on demand through Actions → ROZNEX SEO Agent → Run workflow. The agent audits the actual public domain, NOT the GitHub preview.

## What is active

- Sitemap discovery, live HTTP checks, canonical matching, indexability, title / description / H1 and language, JSON-LD syntax, images, direct conversion links, possible orphan pages and high-value service pages.
- Crawl budgets: 65 URLs maximum; four concurrent requests; 14s per request and one retry.
- Read-only by design. Saves JSON and Markdown reports as workflow artifacts, plus a summary on the run page. No password storage and no accidental public issue spam.
- Severity: critical (indexing and HTTP), warning (content / discovery / conversion), notice (social / enhancement). Rule-based prioritization is NOT a live traffic or ranking model.

## Agent sections and growth responsibilities

1. **Technical SEO auditor:** find crawl/index issues, canonical and hreflang failures, structured data errors and missing page elements.
2. **Conversion path auditor:** ensure each commercial service page can reach the project intake form, and that offers are understandable on mobile.
3. **Editorial strategist (human-approved):** compare search intent with useful firsthand examples. Never fabricate references, photos of clients, certificates, testimonials, figures, performance claims or dates.
4. **Brand & visual guardian:** protect ROZNEX ivory, warm charcoal, warm-gold and editorial layout. Keep the existing flagship robot unless a specific replacement is approved. Select visuals with appropriate licensing and clear documentation.
5. **Measurement layer — NOT YET CONNECTED:** add Google Search Console access in future only after owner verification and least-privilege connection. Track queries, CTR, indexed pages and impressions; add confirmed form submissions as a separate conversion source. Do not confuse views with valid leads.

Verify **roznexstudio.ir** in Google Search Console (free), submit `https://roznexstudio.ir/sitemap.xml`, then connect query and landing-page data by an approved read-only integration.
